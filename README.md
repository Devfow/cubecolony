# Cube Colony

A neurochemistry simulation built in C#.

## Recommended Hosting Options

### 1. Play in Browser (GitHub Pages)
You can play the latest web build directly in your browser:
[https://devfow.github.io/cubecolony](https://devfow.github.io/cubecolony)

### 2. Releases (Executable Downloads)
For standalone builds (Windows, Mac, Linux), you can download the latest release from the [Releases page](https://github.com/Devfow/cubecolony/releases).

### 3. Itch.io Integration
(Optional) Host your game on Itch.io for better discoverability and community engagement. Link from your GitHub README.

## Setup for Your Game

This project is set up to be hosted on GitHub Pages for web-based builds.

1.  **Web Build:** The compiled WebGL/JavaScript build files are located in the `/docs` folder.
2.  **GitHub Pages:** Enabled in repository settings, deploying from the `main` branch using the `/docs` folder.
